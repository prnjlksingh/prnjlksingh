## `$ whoami`

I'm a **Cybersecurity and Digital Forensics student at the National Forensic Sciences University (NFSU)**, interested in understanding how systems fail, how evidence tells the story, and how to turn that knowledge into better security.

My work and learning sit at the intersection of **application security, offensive security, digital forensics, and AI/agent security**. I prefer hands-on labs, reproducible findings, and documentation that explains both the *what* and the *why*.

```text
┌─[ pranjal@security-lab ]──────────────────────────┐
│  focus     : AppSec · Pentesting · DFIR · AI Sec  │
│  approach  : Observe → Validate → Document        │
│  principle : Evidence over assumptions            │
│  status    : Always learning                      │
└───────────────────────────────────────────────────┘
```

## `// areas of focus`

| Area | What I'm exploring |
|---|---|
| **Application Security** | Web security testing, attack-surface review, vulnerability research, and responsible disclosure |
| **Offensive Security** | Reconnaissance, network enumeration, penetration-testing workflows, and security validation in authorized environments |
| **Digital Forensics & DFIR** | Android artifacts, timeline reconstruction, log analysis, and evidence-focused investigation |
| **AI & Agent Security** | Security risks in LLM applications, AI agents, tool integrations, and MCP-style workflows |
| **Security Research** | Reproducible proof-of-concepts, clear technical write-ups, and learning through CTFs and labs |
